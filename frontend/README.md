# ShiftLink 웹 (프론트엔드)

피그마 디자인을 React로 구현하는 프로젝트야.

## 기술 스택
- Vite + React (JavaScript)
- Tailwind CSS v4 (디자인 토큰은 `src/index.css`의 `@theme`)
- React Router v7

## 처음 실행하기
```bash
npm install          # 패키지 설치
npm run fetch-assets # 피그마 아이콘·로고 SVG 내려받기 (처음 한 번)
npm run dev          # 개발 서버 실행 → 터미널에 뜨는 주소로 접속
```
> 브라우저 개발자 도구에서 모바일 화면(예: iPhone 14, 393px 폭)으로 보면 피그마랑 똑같이 보여.

## front 확인할 사항
- 체크박스 **체크된 상태** 디자인 (지금은 진파랑 배경 + 흰 체크로 임시 처리)
- **비밀번호 찾기** 화면이 필요한지 (사이트맵에 없음)
- 입력창 **포커스 / 에러 상태** 디자인 (지금은 포커스 시 테두리 진파랑으로 임시 처리)
- 비밀번호 **보기 상태 아이콘** (피그마엔 숨김 아이콘만 있어서, 보기 상태일 땐 흐리게 임시 처리)
- 비밀번호 불일치 같은 **에러 문구 디자인** (지금은 브라우저 기본 안내창)
- 참여 중인 워크스페이스가 **0개일 때** 화면 디자인
- 워크스페이스 **유형 목록** (피그마엔 '아르바이트'만 있어서 아르바이트/프로젝트/동아리/기타로 임시 처리)
- 워크스페이스 **생성 후 이동할 화면** (지금은 새 워크스페이스의 달력으로 이동)
- 달력 **이전/다음 달 이동** 방법 (디자인에 버튼이 없어서 지금은 오늘이 있는 달만 보여줌)
- **근무 없는 날**을 눌렀을 때 아래 카드 모습 (지금은 빈 막대 + '이 날은 근무가 없어요.')
- **근무 배치 수정, 최소 인원, 멤버 관리**는 관리자만 보여야 하는데, 근무자에게는 버튼을 숨길지 비활성화할지
- 07 **근무자 선택 후 인원이 충족**됐을 때 안내 박스 (지금은 파란 박스로 '최소 인원 충족' 표시)
- 06 **모든 시간대가 충족**됐을 때 화면 (지금은 빨간 박스 없이 '모든 시간대 인원이 충족됐어요.')
- 07·08 **저장 후 이동 화면** (지금은 이전 화면으로 돌아감)
- 09 **멤버를 눌렀을 때** 역할·시급 수정 화면 (디자인 없음, 지금은 눌러도 반응 없음)
- 09 초대 링크 **복사 완료 표시** (지금은 버튼 글자가 2초간 '복사했어요!'로 바뀜)
- 10 **잘못되거나 만료된 초대 링크** 화면 (지금은 임시 안내 화면)
- 시간 선택은 **30분 단위**로 해뒀는데 괜찮은지 (10분, 1시간 단위 등)
- 03 **관리 모드** 화면 (결정: 워크스페이스 관리 → 워크스페이스 선택 → 09 멤버 관리. 안내 박스·흐린 표시는 임시 디자인)
- 03 **'초대받으셨나요?' 카드** 동작 (지금은 누르면 초대 링크/코드 입력칸이 펼쳐지고, 입력하면 10 화면으로 이동)
- 11 대타 요청 **선택 상태** 모양 (지금은 연하늘 배경 + 하늘색 테두리), 선택 없이 지원하기를 누르면 안내 문구 표시
- 11 **지원한 요청**의 표시 (지금은 '지원 완료'로 바뀌고 다시 선택 불가) / 대타 요청 **상세 화면** 필요 여부
- 12 피그마 예시 '9월 12일(토)'은 05 달력 기준 내 근무가 아니라서, 지금은 **오늘 이후 첫 내 근무(9월 9일)**가 기본 선택돼 (06에서 들어오면 그 날짜)
- 14 **확인 완료 후 버튼** 모양 (지금은 비활성 + '확인 완료한 공지예요')
- 14 새로 작성한 공지는 두 번째 카드 제목이 없어서 **'공지 내용'**으로 표시 (피그마는 본문 위에 별도 제목이 있음 → 15에 입력칸이 필요한지)
- 13 **공지 수정·삭제** 기능 필요 여부
- 16 **급여 확인으로 가는 버튼** 위치 (디자인에 없음 → 지금은 05 '이번 달 예상 급여' 카드를 누르면 이동)
- 16 **월별 급여 내역 보기** 화면 (디자인 없음, 지금은 눌러도 동작 안 함) / '이전 근무 N건'을 펼쳐 보는 화면 필요 여부
- 16 급여 예시(64시간)는 피그마 그대로라 **05 달력의 근무 일정과 계산이 맞지 않음** → 백엔드 연결 시 실제 근무 기록 기준으로 맞추기
- 17 **비밀번호 변경·알림 설정** 화면 (디자인 없음, 지금은 보기 전용)
- 17 **저장 완료 표시** (지금은 버튼 글자가 2초간 '저장했어요!')

## 백엔드 연결 필요 사항
- 로그인 후 **사용자 정보(이름·이메일·연락처)** 받아오기 → `UserContext`에 넣으면 상단바·인사말·17에 자동 반영 (지금은 '김민수' 임시 데이터)
- 내 정보 수정, 로그아웃(토큰 삭제), 이번 달 급여·근무 기록
- 워크스페이스 목록 / 생성
- 내 근무 일정, 이번 달 예상 급여, 최근 공지
- 날짜별 근무 배치·시간대별 최소 인원(부족 계산), 배치 저장
- 최소 인원 규칙 목록·저장, 멤버 목록·초대 코드 발급, 초대 코드로 워크스페이스 조회·참여
- 관리자/근무자 **권한 정보** (관리자 화면 접근 제한용)
- 대타 요청 목록·등록·지원·승인, 공지 목록·상세·등록·읽음 처리
