# ShiftLink 웹 (프론트엔드)

피그마 디자인을 React로 구현하는 프로젝트야.

## 기술 스택
- Vite + React (JavaScript)
- Tailwind CSS v4 (디자인 토큰은 `src/index.css`의 `@theme`)
- React Router v7

## 처음 실행하기
```bash
npm install          # 패키지 설치
npm run fetch-assets # 피그마 아이콘·로고 SVG 내려받기 (처음 한 번)
npm run dev          # 개발 서버 실행 → 터미널에 뜨는 주소로 접속
```
> 브라우저 개발자 도구에서 모바일 화면(예: iPhone 14, 393px 폭)으로 보면 피그마랑 똑같이 보여.

## 폴더 구조
```
src/
├─ index.css               # Tailwind + 디자인 토큰(색상, 폰트)
├─ assets.js               # 피그마 에셋 경로 모음
├─ routes/paths.js         # 17개 화면 주소 + 구현 전 화면 목록
├─ contexts/               # 앱 전체 공유 상태 (선택한 워크스페이스)
├─ mocks/data.js           # 백엔드 연결 전 임시 데이터
├─ components/
│  ├─ common/              # 여러 화면에서 쓰는 공통 부품 (Button, TextField, Checkbox, Divider, Logo)
│  ├─ layout/              # 모바일 393px 레이아웃, 상단바·하단 메뉴(AppLayout)
│  └─ auth/                # 로그인·회원가입 전용 (탭, 카드 틀)
└─ pages/                  # 화면 단위 컴포넌트
   └─ auth/
      ├─ LoginPage.jsx     # 01 로그인 ✅
      └─ SignupPage.jsx    # 02 회원가입 ✅
   └─ workspace/
      └─ WorkspaceSelectPage.jsx # 03 워크스페이스 선택 ✅
```

## 진행 상황
| 번호 | 화면 | 상태 |
|---|---|---|
| 01 | 로그인 | ✅ 화면 구현 (API 연결 전) |
| 02 | 회원가입 | ✅ 화면 구현 (API 연결 전) |
| 03 | 워크스페이스 선택 | ✅ 화면 구현 (임시 데이터) |
| 04~17 | 나머지 | 자리표시 페이지만 연결 |

## 형한테 확인할 것
- 체크박스 **체크된 상태** 디자인 (지금은 진파랑 배경 + 흰 체크로 임시 처리)
- **비밀번호 찾기** 화면이 필요한지 (사이트맵에 없음)
- 입력창 **포커스 / 에러 상태** 디자인 (지금은 포커스 시 테두리 진파랑으로 임시 처리)
- 비밀번호 **보기 상태 아이콘** (피그마엔 숨김 아이콘만 있어서, 보기 상태일 땐 흐리게 임시 처리)
- 비밀번호 불일치 같은 **에러 문구 디자인** (지금은 브라우저 기본 안내창)
- **워크스페이스 관리** 버튼이 어느 화면으로 가는지 (사이트맵에 없음, 지금은 눌러도 동작 안 함)
- 참여 중인 워크스페이스가 **0개일 때** 화면 디자인
